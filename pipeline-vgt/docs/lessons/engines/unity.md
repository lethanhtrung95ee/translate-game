# Bài học engine Unity

Quy tắc dùng: `docs/lessons/README.md`. Chỉ đọc khi game đang làm là Unity.

Hiện mới có **1 game Unity** (Legend of Mortal) nên theo quy tắc nâng phạm vi, các bài học kỹ thuật vẫn ở mức game:
`docs/tham_khao/LEGEND_OF_MORTAL.md` mục 4–6 (bảng localize, Phồn/Giản thể, font TMP, chữ cứng trong dll, patch theo offset, UI tràn chữ).

Khi làm game Unity thứ 2: kiểm từng mục đó bằng "Dấu hiệu kiểm tra" trên game mới. Mục nào khớp lại → viết thành `E-unity-###` ở đây theo mẫu.
